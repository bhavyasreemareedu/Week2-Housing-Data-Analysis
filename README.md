# 🏠 Exploratory Data Analysis of Housing Prices

## 📌 Project Overview
This project focuses on Exploratory Data Analysis (EDA) of a housing dataset using Python. It explores housing prices, property areas, bedrooms, bathrooms, furnishing status and other features to understand patterns and relationships in housing data.

The project uses NumPy, Pandas and Matplotlib for numerical computations, data manipulation and visualization.

## 🎯 Objectives
- Understand and explore the housing dataset.
- Perform data cleaning and preprocessing.
- Apply NumPy for numerical calculations.
- Use Pandas for data manipulation and analysis.
- Perform grouping, aggregation, merging and pivot table operations.
- Visualize housing data using Matplotlib.
- Identify useful insights from the dataset.

## 📂 Dataset Information
- **Dataset:** Housing.csv
- **Total Records:** 545
- **Total Columns:** 13
- **Data Type:** Numerical and categorical data

## 📊 Project Implementation

### 3. Matplotlib

## 📈 Visualizations
The project includes visualizations to understand:
- Average housing prices by furnishing status.
- Distribution of housing prices.
- Relationship between house area and price.
- Average price based on the number of bedrooms.
- Distribution and outliers in housing prices.
